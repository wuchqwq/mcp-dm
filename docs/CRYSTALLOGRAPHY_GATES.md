# 晶体学分析：哪些限制必须守住，哪些可以按任务配置

目标是让一次分析尽量自动完成，同时说清“没有匹配”的具体范围。
不能把所有限制都当成科学定律，也不能为得到期望物相反复放宽条件。
使用步骤见[晶体学工作流](CRYSTALLOGRAPHY_WORKFLOW.md)。

## 不随分析结果放宽的边界

- 原生构建/ABI 指纹、操作资格、图像与会话身份、源保护和引用生命周期。
- 数值文件哈希、dtype、轴序、源 ROI、单位及 cycles/radians 约定；不能用显示 PNG
  冒充科学数值，不能由候选相反推并暗改标定。
- 原生 FFT 只用已验证的类型和尺寸；扩尺寸要有相应的数值、内存和实机验收，
  不能只改一个上限。缺接口或资格时不切换隐藏的外部 FFT。
- 现有计算预算仍有效：伴随工具有界输入、定位候选数、索引搜索种子数和文件独占写入。
  超预算要明确报告；部分搜索结果不能冒充已完成搜索。

## 可预先声明的科学比较条件

`max_index`、径向/角度容差、允许未匹配点数、指定 CIF 和有限 `c/a` 网格
属于明确的分析设置。先依据预计反射阶数、标定和测量误差保存设置，再运行比较。
不同候选用同一份冻结点表和同一误差政策；改变条件时保留原结果及改变依据。

当前索引默认 `max_index:3`、`relative_tolerance:0.03`、
`angle_tolerance_deg:2`、`max_unmatched:0`。索引上限可显式选 1..4；
六方上限同时约束 `|h|,|k|,|i=-h-k|,|l|`。
未匹配点需逐点保留，不能把它们删掉后声称整张图满足同一晶体模型。
允许未匹配不是对多晶重叠、畸变或层错的自动解释。

索引阶数和误差容差是两回事。例如已知立方晶胞的 `[001]` 投影包含
`±220`、`±(2,-2,0)`、`±400`、`±040` 八个反射时，`max_index:3`
没有枚举 `400/040`。在完全相同的 3%/2°/零未匹配政策下，显式枚举到 4
可以检验它们，不需要增大误差容差。独立回归见
`tests/test_crystal_gate_controls.py`；这个合成几何对照不是实验判相证据。

目前一个角度参数同时约束单点方向、种子反射对夹角和最终全部匹配点的两两夹角。
因此“每个点方向都差不到 2°”不一定满足“两两夹角都差不到 2°”。解释结果时
同时检查候选的单点残差和 `max_pair_angle_residual_deg`，不要把这些量混为一谈。
固定容差也不是统计置信度；自动定位的未知误差仍是未知。

## 多测反射，不必把所有点都塞入同一次搜索

12 点是当前联合索引的计算边界，不是最多只能观察 12 个反射。
现有接口已经允许自动测量最多 32 点，或显式测量最多 128 点；测量与索引可以分开：

1. 先按实空间纹理、取向一致性和域边界选择局部 ROI，保存坐标和选择依据。
   不先试物相，再挑最容易得到该物相的区域。
2. 对同一份固定捕获运行 `spots:"auto"`、`detection.max_spots:32`、
   `indexing.enabled:false`，保留全部返回的测量、定位诊断和点位图。
   定位本身也有候选预算和排除条件，32 是输出上限，不保证每张图都能取得 32 点。
3. 在比较物相前冻结选择规则及点 ID，例如在预先规定的频率范围内按半径排序，
   保留完整 Friedel 对并覆盖多个方向；选不超过 12 点用于索引，其余点留作验证。
   保存被排除点和原因，不能按哪个子集最像目标相反复试选。
4. 用现有显式 `spots` 列表发起第二次外部分析请求；坐标取第一次测量的
   `source_xy`，仍为源图像像素中心 XY，沿用同一捕获、标定及参考 CIF。
   每次分析保存新请求 ID 和新输出目录，无需重做或重发 DM 操作。
5. 使用候选已经拟合好的共同取向和固定晶胞，检查其余反射的预测位置、径向和角度
   残差；验证时不重新拟合。记录匹配与未匹配点。没有额外点时，只能说拟合内一致，
   不能称作独立验证。

这是已有测量和显式点输入的组合方式，不是新增自动选域或验证 API。
对照同一候选的额外反射可以加强或否定几何解释，但不把单张图变成唯一物相证明。

## 正确解释未匹配、截断和较大 FFT

无共同晶带轴候选表示“在记录的模型、索引范围、容差和点表内没有找到”，
不是软件调用失败，也不是证明该物相不存在。计算完成、测量可用、候选可接受和
化学物相确认是不同结论。保留 `NEEDS_REVIEW`、具体原因及仍可用的测量结果。

输出数量限制不应隐藏多解。检查 `total_distinct_candidates`、
`output_truncated`、F/I/P 或 `c/a` 的兼容集合；当前输出保留各兼容类别代表，
截断时不要只看排在第一位的候选。有限两锚点搜索仍不保证找到全部带噪解。

较大 FFT 区域通常减小数学频率格点间距，但也可能混入其它取向的晶域。
先选单域，再比较有依据的窗口尺寸。`1/L` 是有限窗口的频率分辨/展宽尺度，
不是自动得到的峰定位标准差；零填充也不增加原始实空间信息。
不把 3% 改成更大的数来消除失败，也不把最亮的若干峰默认认作同一晶体。
图像 FFT 的峰位置/几何、SAED 强度、基元消光及最终物相判断仍需分别解释。
