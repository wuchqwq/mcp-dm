# 下一阶段：衍射标定与晶格间距测量

**状态：首版外部伴随工具已实现，实验数据与普通客户端仍待验收。** [运行流程](CRYSTALLOGRAPHY_WORKFLOW.md)支持自动中心/斑点、测量和 FCC/BCC/HCP 几何候选，复用 ASE 晶胞/CIF；不是自动唯一判相。下面保留原始任务与扩大资格范围的验收要求。此用户工作流优先级取代一般剖面、直方图和显示样式；已验收的 GUI 测量与数据交接继续保留。

## 用户真正要完成的工作

用户通常在 DM GUI 中分析衍射图、HRTEM 或 STEM-ADF 图像，测量晶面间距和夹角，给反射索引，并结合材料背景判断候选物相。ROI、profile、FFT、显示与导出是底层能力，不是最终任务。

先交付两个明确、可复核的流程：

1. **衍射图**：用户确认中心和若干斑点 → 检查倒空间标定 → 测量倒空间矢量、间距、长度比和夹角 → 提出 FCC/BCC 等立方候选的 `(hkl)` 与 `[uvw]` → 用额外斑点检验一致性。
2. **HRTEM / STEM-ADF**：用户选定局部区域 → 使用已支持的 DM 原生 FFT，或显式选择另一条已记录的外部路径 → 测量若干空间频率及夹角 → 比较指定候选结构，交付区域、频谱位置、测量表和依据。

第一版不要求自动找出全部斑点，不要求通用自动判相，也不要求新建原生点选区接口。明确的源坐标点表可以作为输入；不要让一般斜线 profile 的 ABI 成为点到点几何测量的前置条件。

## 分工与实现边界

- **MCP / Native Bridge**：选对数据，保留轴/单位/来源；执行已确认的 DM 原生处理，提供有界预览、数值交接及可查询结果。既有源保护、请求身份、结果释放和构建门禁不变。
- **可选外部晶体学工具**：允许建立小型、确定性、可测试的几何测量与候选匹配伴随工具，显式读取已交接的数据/坐标/标定并保存参数。这不是插件内的第二套科学计算引擎，不是缺失原生算子的隐藏 fallback，也不能冒称 Gatan/DIFPack 计算。
- **Agent**：澄清输入、组织步骤和解释证据；不凭语言推断生成最终晶面指数或相名。保留输入、程序版本、测量参数和候选残差。
- **Codex**：负责这个端到端任务、几何计算、集成及测试。
- **DeepSeek**：只有当工作流被具体原生接口阻塞时，定向调查标定、峰坐标精化或必要数据访问；不继续无边界探索样式和窗口控制。

代码可在独立工作树并行；真实 DM 测试同一时间只有一个明确负责人。不创建新的多 Agent 调度平台。

## 第一批：先让测量可核对

输入至少绑定图像/捕获身份、源区域、轴序、尺度及单位、显式中心、点坐标及坐标约定。区分实际衍射图与实空间图像的 FFT。

- 把“像素到倒空间尺度的标定”与“指定 `(hkl)` 的索引”作为不同步骤；不得为了拟合一个物相而暗中改标定。
- 显式声明频率约定：`|g|=1/d` 的 cycles/length 与 `|q|=2*pi/d` 的 radians/length 不能混用；nm 与 angstrom 的转换也必须可追溯。
- 在物理坐标中计算长度和夹角，保留 signed scale、非零原点和轴顺序；不把显示窗口或缩小 PNG 的坐标当原始像素坐标。
- FFT 采用已有 `frequency_grid` 和中心信息，不只依靠 DM 显示标定的半格偏移。裁剪和 READ 偏移必须组合。
- 缺绝对标定时不输出绝对 d；可在声明各向同性等前提后提供无量纲长度比/几何候选。各向异性或畸变未知时，标明角度解释的限制。
- 用户可确认中心或对称斑点对。图像中点、最亮点、FFT DC 和衍射直射束中心不能未经说明互换。提供的中心不确定度与斑点定位误差应记录；无法估计时明确未知。
- HRTEM/ADF 的 FFT 首先是图像的空间频率证据，不等同于已测得衍射强度或唯一物相。说明投影、倾斜、多重散射及成像传递可能造成的解释限制。

首个可运行交付应输出：每个点的物理矢量、d 或明确的不可计算原因、矢量长度比、成对夹角、标定依据，以及供用户核对位置的叠加图/点表。叠加只用于显示，不改变科学数组。

## 第二批：受限的立方候选索引

在预先记录的索引搜索范围和误差政策内，枚举 FCC/F 与 BCC/I 候选。可带 P 候选作歧义对照；不是所有材料都必须归入 F 或 I。

- 使用立方度量、中心化反射条件、成对夹角与共同晶带轴关系进行联合检查；多个斑点必须共享同一取向和一致晶格参数，不能逐点独立挑最接近的 d。
- FCC/BCC 是晶格/结构候选，不是具体化学相名称。结构基元的附加消光条件、双重衍射等影响不能被简单奇偶规则替代。
- 返回多解、残差、未匹配反射与缺失证据。某些晶带几何仅凭比值和夹角无法区分 F/I/P，不能强制返回唯一解。
- 用户指定的已知晶格参数、成分或候选 CIF 是单独输入，不是自动获取的真值。先完成限定立方候选；再按真实需要接入结构文件和已有晶体学库。
- 不把反射强度直接当成体积分数，不把单个 d 匹配当成物相确认；候选相识别不等于定量相组成。

## 验收与停止条件

独立合成真值覆盖：已知立方晶格和晶带、旋转/镜像、非零中心、signed/anisotropic scale、单位与 2*pi 约定、非零裁剪偏移、标定缺失、共线/重复点、多解、噪声及不匹配斑点。至少保留一个 F/I/P 几何歧义案例，证明工具不会伪造唯一相。

高分辨图像流程先用已知频率的非对称合成条纹，通过现有局部 FFT 核对周期、方向和裁剪坐标。保持现有 FFT 尺寸限制，不为演示直接删除预算；需要更大尺寸时另做数值和内存验收。

之后只在明确授权的实验数据副本/小区域上与用户的 DM 手工测量比较。最终让普通 Agent 完成一个真正的衍射测量任务，而不是再以画线/直方图作为产品验收终点。记录人工介入、总步骤、失败原因及科学结果可复查性。

本轮不扩展柱形样式、通用窗口管理、自动兼容层、4D-STEM、硬件控制、通用全自动物相识别或新报告平台。现有 FFT 精度 FAIL 和不完整实机范围照实保留，不通过更换算法或放宽门限消除记录。
