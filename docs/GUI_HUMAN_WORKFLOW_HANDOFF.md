## 已实现

1. 选择工具保持可见的 select 模式；只有实际命中标记/控制点才进入一次拖动。空白拖动创建 ROI，不会平移旧标记；空白点击清空选择。仍拒绝多面板映射不唯一的标注编辑。
2. 统一按用户动作顺序记录科学标记编辑、显示草稿和选区；Gamma 连续输入合并成一项。撤销/恢复有动作名称；科学编辑仍是补偿版本，不删除历史。自动派生的测量标签不另占一项用户撤销。
3. ROI/FFT/测量/统计/剖面按选择类型提供操作，并在创建标注前再次验证。实空间测距用“测距 n”，倒空间点用“gn”。
4. 保存视图的返回/前进/原图入口，复用已有 show/preview；不为导航重算 FFT。同一科学网格的标注/显示修订保留视图位置。跨 FFT→实空间选帧不再继承 FFT 的 gamma/灰度上下限；实空间帧间固定范围比较仍保留。
5. 结果区改为测量、ROI 统计、强度剖面三个页签；适用的统计/剖面动作放到选区旁。修复结果行 hover CSS 的 data 属性。
6. 剖面加横纵数值刻度、量名/单位、悬停和键盘读取真实采样值，表格行与曲线标记联动；不插值伪造采样。探针保留科学坐标显示。
7. 活跃 Panel 分别保留最近统计和最近剖面；浏览器刷新不因另一次统计/测量覆写 last_operation 而丢掉刚看的剖面。恢复仍核对网格/标定。
8. 区分科学数据导出（工作区目录）、论文图片下载和测量 CSV/TSV。

GUI 调用相同 provider、单位/坐标与原请求恢复路径。没有更改 Python 科学数组算法、DM ABI、默认后端或 #46 入口。
