# 下一阶段：让分析工具支持探索、纠正与继续

> 开发路线，不是已实现能力声明。基于 PR #26 `2e18923` 的审查；集成前核对实际分支和测试状态。PR #27 的离线 GMS 兼容工具独立审查，本路线不合入或修改它。

## 产品目标与边界

mcp-dm 是通用 Agent 的显微科研工具与数据交接接口，不是固定判相程序。研究者可在 DM 中处理半成品，Agent 接过明确的当前科学数据，调用图像、结构与衍射工具，再把受支持结果交回新的 DM 工作图；独立 TIFF、CIF、XYZ 不必经过 DM。

确定性程序负责数值、坐标、标定与来源；Agent 负责选择工具、提出和检验假设、接受人的纠正。GUI 只承担展示、定位和必要纠正。先用好已接入的 ASE/diffsims，不扩聊天平台、通用调度器或新 GUI 框架，不为凑通过而降低科学阈值或原生资格要求。

相关契约：[连续分析](CONTINUING_DIFFRACTION.md)、[中心修订](CENTRE_REVISIONS.md)、[受约束配准](CONSTRAINED_REGISTRATION.md)、[反射比较](REFLECTION_COMPARISON.md)、[DM 数值交接](DM_NUMERIC_RELAY.md)。

## 本轮小修复的验收目标

- 同一保存频谱的显示版本可以不同：gamma、标注、显示缩放不是新科学数据。共同配准应核对原科学网格、数组身份与有效标定，而不是要求显示对象 ID 完全相同。保留显示来源，不准仅凭数组内容相同跨独立捕获、帧或 FFT 生产者自动移植点位。
- 自由文本背景不是坐标域的结构化声明。用户先说明“这是 SAED”，再明确设置倒空间标定，不应仅因已有文字就被阻止。未知输入的显式声明必须保留实际用户依据和原背景；已知实空间标定/谱系、已建立域及明确的实空间重构语义仍不得静默改写。
- 证据必须包含修改前失败、修改后通过的真实工作区/工具组合回归；静态反例不能代替完整链路。最终执行范围放在 PR，不把 Windows、真实 DM、浏览器与合成测试混称为一个 PASS。

## 开发顺序

### A. 优先：让 Agent 可以提出候选，而不用冒充用户已确认

当前严格配准只接受 `user_confirmed` / `synthetic_fixture`。下一步评估增加明确的候选假设来源，例如 `agent_hypothesis`，或独立探索入口。复用同一个确定性配准/比较实现，保持实验尺度、中心、屏幕轴约定和数值门禁，不为了探索暗加伸缩或镜像自由度。

候选与确认是证据层级，不是两套不同质量的数学。探索结果应显示假设来源、输入对应、残差和未解释的反射，不能记为用户确认或唯一物相。记录人确认/否定后的新版本，旧假设保留。未参与拟合的反射可以检验候选，但若已被用于挑选模型/对应，就不能再包装为未触碰的独立验证集；保留这种选择过程的限制。

首个验收：Agent 从图像和候选 CIF 提出至少两个明确标记的解释，调用工具比较；研究者纠正一个点或否定一个对应，Agent 继续而不是要求人先完成整张图的索引。案例是验收，不是强制工作流。

### B. 优先：失败应有可行动的证据

将失败分为传输/调度、输入或坐标不匹配、科学候选不一致。不要让它们都变成“失败，请重试”。

**RPC deadline 诊断：**用同一代码和输入，分别记录排队、进程启动/依赖导入、读取/哈希、计算、持久化、PNG/传输阶段。对照空闲与受控并行负载、以及未修改基线。日志默认不含实验像素、私人路径或令牌。超时后查询原请求；不要新 ID 重发可能有副作用的操作。只有定位原因后才决定调整测试调度、缓存、进程复用或超时预算；不全局拉长期限、反复重跑至绿、跳过失败用例。就绪回归通过不代表一般延迟已合格。

**科学不一致：**输出配对、固定标定、容差、原始/变换后反射坐标、残差、未匹配和候选歧义。给出可查看的叠加/残差图，图仅是数值结果的展示，复用现有绘图/标注工具。明确哪些点用于拟合、验证或仅观察。拟合失败不等于程序崩溃；验证点不一致不能触发自动重拟合或扩大容差来掩盖。

### C. 收敛：在真实多轮分析中保持正确版本

保持一个轻量的当前任务引用：捕获/帧/ROI、科学网格、有效尺度与中心、点位、测量、结构/取向、配准。优先复用现有不可变对象和父子关系，不先建数据库。

显示变化不使科学测量失效；尺度/中心/点位变化只更新相应派生结果；旧测量及导出继续作为历史。用户说“我在 DM 改过了，再看看”必须新捕获，不能将原 request ID 的结果查询当作实时读取。同 ID 原地修改用独立合成工作图、独占宿主、明确的采前/采后状态验证，不宣称任意并发编辑的原子快照。

数据类型/尺寸不足时先报告具体阻塞。绝不为满足当前接口而静默量化、缩图或改单位；按真实任务优先扩展，且原生新范围独立资格验证。

### D. 后续：扩大最有价值的分析能力

在 A–C 跑通后，根据真实例子决定先做批量反射测量/局部峰位精化与误差、更多 TIFF 浮点类型、较大有界 DM 导入，还是多取向/孪晶候选的几何比较。不是同时全做。高保真散射模拟、自动结构判定、广泛 ABI 适配与 GUI 编辑器暂不成为本轮前置条件。

## 科研验收与用户分工

研究者提供一份熟悉的本地实验数据、尺度来源和候选 CIF；不确定项可保持未知。可给少量有把握的对应，保留其他反射作后续检查。样本不得提交公开仓库。Codex 负责环境、MCP 调用、内部 ID、记录、回归和导出，不要求人输入 JSON。

建议验证一次：DM 半成品或独立 TIFF → 观察/测量 → 参考结构/晶带轴/模拟 → 调显示继续测点 → 候选配准 → 人修正尺度、中心或点位 → 重新比较未拟合反射 → 在已验证范围内交回 DM 新工作图。保留原图与复数频谱，测试所述流程并不规定 Agent 的分析顺序。

报告工程正确性、模型是否实际看到了图、科学比较是否成立、人实际做了哪些步骤，四者分开。图像漂亮、测试数多、请求成功都不能代替实验解释成立。

## 给 Codex 的执行任务

从最新集成基线接续，先检查 #26 与本修复 PR 的实际状态；不重复合并旧分支，不碰 #27。确认两个误拒绝的修复和回归后，优先交付 A 与 B 的最小实用能力，再用 C 的真实多轮实例检验。

具体接口、模块、依赖与顺序由你决定。可以大胆提出候选，但不能伪造用户确认；科学计算保持严格，证据与来源诚实。只修阻碍使用的 GUI，不扩平台。缺真实数据时先做合成开发，列清待人工验收项，不全线等待。

独立分阶段提交、开 PR，暂不自行合并 main。最终重点报告：Agent 新增了什么探索能力；错误后能否采取有效下一步；改显示和改科学信息分别影响哪些结果；用户少了哪些手工步骤；实际验证范围；下一项最值得处理的阻塞。
